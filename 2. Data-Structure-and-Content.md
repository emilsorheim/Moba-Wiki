# Data Structure and Content

## Overview

MoBa data is distributed across multiple datasets representing:

- Questionnaire data collected at different time points  
- Participants (mothers, fathers, and children)  
- Registry-based data  
- Derived and project-specific datasets  

MoBa is a **longitudinal, relational dataset**, meaning that:
- Participants are followed over time  
- Data is spread across multiple files  
- Datasets must often be merged for analysis  

A correct understanding of structure and identifiers is essential before working with the data.

---

## Core Entities

MoBa is built around three main participant groups:

| Entity   | Description |
|----------|------------|
| Mother   | Woman enrolled during pregnancy |
| Father   | Partner of the mother |
| Child    | Offspring followed from birth onward |

These entities are typically linked through shared identifiers.

---

## Units of Observation

The unit of observation varies across datasets:

- **Pregnancy-level data**  
  - Used for questionnaires during pregnancy  
  - One row per pregnancy  

- **Child-level data**  
  - Used for post-birth questionnaires and registry data  
  - One row per child  

⚠️ This distinction is critical when merging datasets.
