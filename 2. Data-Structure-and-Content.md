# Data Structure and Content

## Core Structure

MoBa is a longitudinal, population-based cohort dataset with repeated data collection from pregnancy onwards. 

Data are collected at multiple time points from pregnancy through later follow-up. As a result:

- individuals are observed repeatedly  
- participation varies across time



The data are distributed across multiple datasets and must be linked prior to analysis.

The structure of MoBa is defined by three elements:

- the unit of observation  
- the identifier structure  
- the distribution of data across datasets and time points  

These elements determine how the data can be combined and analysed.

---

## Units of Observation and Identifiers

MoBa data are defined at two observational levels:

| Level      | Description |
|-----------|------------|
| Pregnancy | One record per pregnancy |
| Child     | One record per child |

The pregnancy is the relevant unit during gestation. After birth, the child becomes the relevant unit.

Observations are identified using:

- `PREG_ID` (pregnancy identifier)  
- `BARN_NR` (child identifier within pregnancy)
- 'M_ID' (Mother's identifier)
- 'F_ID' (Father's identifier) 

This distinction determines how datasets can be linked and how relations within Moba are identified. Linkage follows directly from the identifier structure:

- Pregnancy ↔ pregnancy datasets are linked using `PREG_ID`  
- Child ↔ child datasets are linked using `PREG_ID + BARN_NR`  
- Pregnancy ↔ child datasets are linked using `PREG_ID`, followed by expansion to child-level  

These operations define the permissible ways in which datasets can be combined.

---

## Analytical Implications

The structure described above imposes a set of constraints on analysis:

- the unit of observation must be explicitly defined  
- identifiers must be specified consistently in all linkage operations  
- variables must be evaluated with respect to time point and version  
- the relationship between exposure and outcome must be temporally aligned  

Violations of these constraints will result in incorrect data structures and potentially biased estimates.

---

## Summary

MoBa data analysis requires:

- explicit specification of the observational unit  
- consistent use of identifiers  
- controlled linkage of datasets across time  

These are necessary conditions for valid statistical inference.
